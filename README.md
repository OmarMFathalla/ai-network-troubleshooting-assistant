# Network Troubleshooting Assistant

A Python-based command-line troubleshooting assistant that helps users identify common network connectivity problems through guided questions and basic diagnostic logic.

## Current Features

- Accepts a user's description of a network problem
- Detects common issues such as:
  - Slow or lagging internet
  - Dropped connections
  - No internet access
- Uses follow-up questions to narrow down possible causes
- Distinguishes between device-specific and network-wide problems
- Provides basic troubleshooting recommendations
